# Support

## Get Help

For help using RepoHealth, [open an issue](https://github.com/AGESILAS3118/repohealth/issues) and describe what you are trying to do.

## Report a Bug

Use the [Bug Report issue template](https://github.com/AGESILAS3118/repohealth/issues/new?template=bug_report.md) to report a reproducible problem.

## Suggest a Feature

Use the [Feature Request issue template](https://github.com/AGESILAS3118/repohealth/issues/new?template=feature_request.md) to propose an improvement.

## Ask a Question

If GitHub Discussions are enabled for the repository, use [Discussions](https://github.com/AGESILAS3118/repohealth/discussions) for questions and general ideas. Otherwise, open an issue.
